## "무엇을 고치려면 어디로?"

| 하고 싶은 일 | 파일 |
| --- | --- |
| 책/페이지 데이터에 필드 추가 | `core/src/common/models.ts` → `core/src/core/book.ts` 또는 `page.ts` |
| 페이지 DOM 구조 변경 | `core/src/core/pageEl.ts` (+ `flipview/src/flipView.css`) |
| 책 한 권의 모습 (표지·책등·두께·호버) | `core/src/core/bookObjectEl.ts`, `bookObject.css`, `common/bookObjectMetrics.ts` |
| 책이 뷰어로 날아가는 경로·시간 | `core/src/common/flightPath.ts`, `core/bookFlight.ts`, `bookShelfManager.ts` 의 `*_FLIGHT_DURATION` |
| 격자·책장 배치, 선반 모양 | `shelf/src/bookShelf.ts`, `shelf.css` |
| 넘김 애니메이션 속도/곡선 | `flipview/src/flipManager.ts` (`animateFlip`, `animateReadyToFlip`), `flipView.ts` (`autoFlip`) |
| 접힘 모양 계산 | `flipview/src/flipManager.ts` `flip()` |
| 그림자 | `flipview/src/flipView.ts` `setShadow1/3/5/6`, `flipView.css` |
| 마우스 반응 영역 크기 | `flipview/src/flipView.css` `#mzZone*` |
| 새 뷰 플러그인 | `packages/scrollview` 를 복사해서 시작 |
| 번들 구성 | `packages/minjs/src/index.js`, `rollup.config.js` |
