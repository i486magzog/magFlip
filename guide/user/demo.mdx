# Live Demo

아래 데모는 **로컬에서 빌드한 소스 코드**(`packages/minjs/magflip.min.js`)로 동작합니다.

1. 책 썸네일을 클릭해 뷰어를 엽니다.
2. 페이지 모서리에 마우스를 올리면 모서리가 살짝 들립니다. 드래그해서 넘겨 보세요.
3. 왼쪽 위 툴바의 `Prev` / `Next` / `Move` 버튼과 줌 슬라이더를 사용해 보세요.
4. 오른쪽 위 `X` 버튼으로 뷰어를 닫습니다.

<DemoFrame />

:::tip 데모가 보이지 않나요?
magBookDocs 저장소에서 `npm run build:magflip` 으로 옆의 magBookFlip 을 빌드한 뒤 `npm start` 하면 데모가 복사됩니다.
공개 데모는 [GitHub Pages](https://i486magzog.github.io/magFlip/examples/prebuild/magflip.html)에서도 볼 수 있습니다.
:::
